# Captain Zakes' Joke Vault

This is the official repository for **Captain Zakes' Joke Vault**, a simple, fun web page dedicated to serving up classic dad jokes.

## About The Project

Captain Zakes' Joke Vault is a minimalist web application designed to bring a smile to your face with a single click. The page has a clear and simple purpose: to provide a dad joke on demand.

## How It Works

The webpage is incredibly easy to use:
1.  Navigate to the page.
2.  Click the "Click the button below to get your first dad joke!" button.
3.  A dad joke will appear, and the counter will increment to show how many jokes have been served.
4.  Keep clicking for more laughs!
